# AGENTS.md

## Scope

This directory is the Ghost theme for hanatane.net. It started as a fork of [TryGhost/Source](https://github.com/TryGhost/Source) but is now developed independently: upstream is no longer merged, and the old `sync-upstream` workflow has been removed. Keep changes focused on theme source, generated assets, and package metadata.

## Commands

Run from this directory, or use `pnpm --filter ./theme <script>` from the repository root.

```bash
pnpm install --frozen-lockfile   # at the repository root
pnpm dev
pnpm test:ci        # gscan (fatal issues only)
pnpm test           # gscan (all warnings)
pnpm test:scripts   # node:test for scripts/**/*.test.mjs
pnpm zip
```

Run the tests before opening a PR when theme files, generated assets, dependencies, or CI change. CI lives in `.github/workflows/test-theme.yml` and `deploy-theme.yml` at the repository root.

## Related automation

- `scripts/hyperstrata-sync.mjs` (run by `.github/workflows/hyperstrata-sync.yml`) tags citations and regenerates `assets/graph.json` via the Ghost Admin API. It also precomputes the citation pane columns (`paneCol` / `paneLanes` on each post) with `scripts/pane-layout.mjs` (width-limited coordinate assignment on top of `scripts/coordinate-solver.mjs`); `assets/js/strata-graph.js` only draws those values and refuses a `graph.json` without them.
- `partials/post-share.hbs` (rendered at the end of every post by `post.hbs`) is the share row: a "Post your thoughts" button that opens X / Bluesky / Threads / Facebook intent links, a title+URL copy button, and a "Copy for AI" button that converts the post body to Markdown in the browser (`assets/js/post-share.js`) and can append the posts related through `assets/graph.json` (citations and researcher annotations, both directions) by fetching each post page. Tests in `scripts/post-share.test.mjs` use jsdom for the HTML-to-Markdown part.
- UI strings go through the `t` helper. The site locale is `ja`, and Japanese overrides live in `locales-local/ja.json`; `pnpm build` (the `locales` gulp task from `@tryghost/theme-translations`) merges them into the tracked `locales/ja.json`, so edit `locales-local/` and rebuild rather than editing `locales/ja.json` directly. Keys without an override fall back to the English key text.
- OG images for posts without a feature image are pre-generated by `ogp/` (see `.github/workflows/sync-og-images.yml`) and stored in each post's `og_image`, so `{{ghost_head}}` emits them without theme changes. The `ogp_generator_url` custom setting and `partials/auto-ogp.hbs` exist for the runtime-generation variant and are unused while it is empty.

## Boundaries

- Edit source CSS, JavaScript, Handlebars templates, partials, and package metadata intentionally.
- Keep generated assets/built/ files in sync when source assets change; the repo tracks those outputs.
- Do not commit node_modules/, local Ghost content, generated zip files, or secrets.
- Never open pull requests against TryGhost/Source. Always pass `--repo mtane0412/hanatane` to `gh pr create`.
